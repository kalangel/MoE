# ⚜ Марш Империй

Локальная браузерная стратегия в стиле March of Empires: свой замок, карта мира с ботами,
бои, щиты, фракции, исследования и полноценный офлайн-прогресс.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173. Прогресс хранится в localStorage и переживает перезапуск.

## Онлайн (Supabase)

Общий мир на 5–10 игроков. Ключи берутся из `.env` (`VITE_SUPABASE_URL`,
`VITE_SUPABASE_ANON_KEY`) через `import.meta.env` — в коде не хранятся.

1. В Supabase → **SQL Editor** выполни скрипт [`supabase_schema.sql`](supabase_schema.sql)
   (создаёт таблицы `players`, `events`, `attacks`, политики RLS и realtime).
2. В **Authentication → Providers** включи Email (для быстрого теста можно отключить
   «Confirm email»).
3. Запусти игру — появится экран входа (email+пароль) или «Играть оффлайн».

Что даёт онлайн:
- вход по email+паролю (Supabase Auth);
- все игроки видят замки друг друга (ник, сила, щит) на одной карте;
- атака на реального игрока по текущей боёвке; донесение приходит в Почту защитнику
  (применяется при следующем заходе, если он офлайн);
- щит спадает при своей атаке, под щитом бить нельзя;
- общая лента событий внизу карты (realtime);
- боты остаются у каждого (одинаковые правила), ресурсы/щиты/марши тикают по реальному
  времени даже офлайн.

Если `.env` не задан — игра работает полностью оффлайн, как раньше.

Продакшен-сборка: `npm run build` → папка `dist/`.

## Стек

React 18 + Vite + TypeScript · Zustand (состояние) · Framer Motion (анимации) · SVG-графика.

## Интерфейс (олдскул-оболочка)

- **Полный экран**: игра занимает весь вьюпорт (`position:fixed`, 100vw/100vh, без скроллов),
  панели зафиксированы поверх поля, карта скроллится под ними. Кнопка ⛶ в верхней панели и в
  Настройках — нативный Fullscreen API.
- **Стиль**: тёмное состаренное дерево + кованое золото/латунь, круглые медальоны-иконки в
  золотых ободках, шрифт с засечками, красные бейджи-счётчики, зелёные/синие объёмные кнопки.
- **Нижняя панель** (11 медальонов): Город · Кампания · Армия · Союз · Предметы · Почта ·
  Профиль · Рейтинги · Лотерея · Эталон · Настройки. Каждая открывает **полноэкранную страницу**
  (не всплывающее окно) с единой кованой шапкой: слева круглые «‹» (назад) и «i», по центру
  название золотым шрифтом, справа счётчик золота + монета с зелёным «+».
- **Страницы** используют разделители секций (тёмно-золотой фон, бордовый заголовок по центру)
  и строки статистики (чёрная подпись слева, зелёное число справа) на светлом фоне списков.
- **Верхняя панель** (на карте/в городе): портрет с уровнем замка, ресурсы
  (еда/дерево/железо/серебро/золото) с доходом, стопка таймеров активных действий, фуллскрин.
- **Верх карты**: Регионы · Найти · Королевство · Пантеон · Закладки · Миры (контекстные окна).
  Снизу — двухстрочная бегущая «Хроника королевства» (объявления + события мира ботов).
- Город ↔ Карта: круглая кнопка «Карта» (с миниатюрой мира в кованом ободке) в городе и
  «Королевство» на верхней панели карты.

### Профиль
Карточка игрока (портрет в золотой раме с короной и лаврами, уровень, VIP-лента, ник, статус
«Король», плашки «Убитые отряды» и «Общая сила», тег союза, VIP-корона), ряд медалей-достижений
разной формы с красными счётчиками, вкладки Общее/Бонусы/Город. «Общее» — длинный список
статистики секциями «Обзор битвы», «Обзор экономики», «История союза». Все числа — из реального
состояния игры.

### Эталон (страница)
Баннер с крылатым гербом и фиолетовым кристаллом (уровень Эталона) + полоса «ОП Эталона»
(`xp/до следующего`). Секции: «Пропуск Эталона» (премиум-заглушка с переключателем),
«Способности Эталона» (карты с кулдаунами; «Готово» → активирует эффект: бафф/ускорение/ресурсы),
«Бонусы Эталона» (доступные очки, «Сброс бонусов», «Изменить значок», вкладки веток
Война/Экономика/Развитие, сетка узлов с замками, уровнями и растущей ценой). Открыто с Замка ур. 11.

## Эталон (Paragon)

Открывается при **Замке ур. 11** (до этого медальон затемнён с замком и сообщением
«Откроется при Замке уровня 11»). Очки Эталона копятся за бои, задания и постройки.
Три ветки — **Война / Экономика / Развитие** — с последовательными узлами (следующий
открывается после предыдущего), у каждого узла уровни и растущая цена. Бонусы постоянные и
складываются с бонусами фракции, Академии и Храма: атака/защита/снижение потерь, добыча
ресурсов/трофеи, скорость стройки/исследований/найма. Окно — три вкладки с древом узлов в
золотых рамках и счётчиком очков.

## Визуальный стиль

Мрачное изометрическое средневековое фэнтези (псевдо-3D вид сверху-сбоку):

- **Замки** ([CastleSVG.tsx](src/components/CastleSVG.tsx)) — детализированная крепость:
  серый текстурированный камень (паттерн кладки + градиенты объёма), цилиндрические башни,
  зубчатая куртина, арочные ворота с решёткой и факелами, тёплый свет окон, флаги,
  мягкая тень. Крыши различаются по фракции: конус / луковичный купол / купол / пагода.
  Силуэт растёт с уровнем (донжон, угловые башни, верхний ярус).
- **Королевство** ([KingdomView.tsx](src/views/KingdomView.tsx)) — склон с террасами и
  скальными обрывами, ночное небо с луной, горы, река с мостом и лодкой, ели и камни.
  Постройки лепятся к террасам, у каждой число уровня в кружке.
- **Карта** ([MapView.tsx](src/views/MapView.tsx)) — тёмная пересечённая местность, реки,
  леса, горы. Панорама — через прямой DOM-трансформ (без ре-рендера дерева), статичный
  мир мемоизирован, так что прокрутка не лагает даже при тысячах SVG-узлов.
- Общий набор стиля — [svgKit.tsx](src/components/svgKit.tsx) (палитра, defs, крыши,
  значок уровня). Никаких дорогих SVG-фильтров — тени и свет на градиентах.

## Взаимодействие с целями, бой и ИИ

- **Окно цели** (белое, поверх карты) — клик по чужому замку/казарме: имя, координаты,
  сила (или «???» без разведки) и три кнопки: **В бой**, **Разведка**, **Шпион**.
- **Разведка** — отряд с таймером (10–30 с): грубая оценка силы и состава, сохраняется в отчёт.
  **Шпион** (нужна Таверна, дороже) — точный состав, ресурсы, здания, щит, бонус обороны;
  может провалиться (шанс растёт с уровнем цели).
- **Экран боя** ([BattleScreen.tsx](src/components/BattleScreen.tsx)) — поле построения
  (фланги / центр фронт+тыл / осадный слот / резерв), вкладки по типам (Мечники, Копейщики,
  Кавалерия, Стрелки, Осадные, Спецотряд) с рангами I/II/III, выбор формации (2 базовые +
  3 открываются при Замке ур. 4), «Масштаб похода X/MAX», таймер марша, кнопка «В атаку».
- **Контр-система**: копейщики бьют кавалерию, кавалерия — стрелков, стрелки — пехоту,
  мечники — копейщиков, осадные — укрепления. Формация даёт бонусы своим классам и снижает потери.
- **Телепорт** — клик по пустой клетке карты: перенос замка за 260 👑, карта центрируется.
- **Щиты на карте** — плавающая панель справа; атака мгновенно снимает свой щит, и панель
  сразу доступна, чтобы надеть новый.
- **ИИ-боты** живут фоновым тиком (онлайн и офлайн): качаются, циклично ставят/снимают щиты,
  воюют друг с другом и с казармами, фермят, иногда нападают на игрока (с защитой новичка —
  слабых почти не трогают). События идут в **бегущую «Хронику королевства»** внизу карты.

## Казармы варваров

Нейтральные лагеря на карте мира (уровни 1–3): тёмный частокол с кольями, костёр,
черепа на пиках, рваные флаги, шатры. Атакуются как замки ботов; чем выше уровень —
тем сильнее гарнизон и богаче трофеи (золота дают больше, чем замки ботов). После
разгрома слабеют и восстанавливаются за 3 часа. Уровень 1 — для новичка, уровень 3 — крепкий.

## Механики

- **5 ресурсов**: железо, дерево, серебро, еда — добываются зданиями (доход/час).
  **Золото** — только за победы в боях, отбитые рейды и ежедневные задания. Ферм золота нет.
- **Офлайн-прогресс**: всё на `Date.now()`-таймстампах. Доход, стройки, исследования, найм,
  щиты, походы и даже рейды ботов досчитываются при входе (чанками по 5 минут — здание,
  достроенное офлайн, начинает приносить доход с момента достройки).
- **4 фракции** с уникальными бонусами, юнитами и стилем замка (готика / луковичные купола /
  пустынные купола / пагода). Смена фракции — 2000 золота, армия конвертируется.
- **4 щита**: 1 ч (бесплатный, кулдаун 4 ч), 8 ч, 24 ч, 3 дня. Под щитом замок неприкосновенен.
  Собственная атака снимает щит. Боты без щита иногда совершают рейды на игрока!
- **Жёсткий кап**: ни одно здание не выше уровня Замка.
- **Еда и дезертирство**: каждый воин ест еду/час; при пустых амбарах армия тает,
  пока баланс не выровняется.
- **Бой**: сила = атака армии × бонусы фракции × исследования × благословение Храма
  против силы гарнизона (±8% случайности). Потери у обеих сторон, трофеи победителю.
  Побеждённый бот теряет силу (восстанавливается 2 часа) и может спрятаться под щит.
- **Шпионы** (Таверна): доклад о силе цели с точностью, растущей от уровня Таверны.
- **Храм**: молитва раз в 2 ч — случайное благословение на час.
- **Посольство**: союзники сокращают активные таймеры (кулдаун 4 ч).
- **Академия**: 4 ветки исследований × 5 уровней (экономика, стройка, атака, защита).
- **Ускорения** очередей за золото: 1 👑 = 1 минута.

## Dev-консоль (читы)

Клавиша **`** (тильда/ё) открывает консоль поверх игры. Enter — выполнить, Esc — закрыть,
↑/↓ — история команд. Все команды меняют реальный стор и сразу сохраняются.

| Команда | Действие |
|---|---|
| `give iron\|wood\|silver\|food\|gold <n>` | добавить ресурс |
| `give all <n>` | добавить все ресурсы |
| `army <тип> <n>` / `army list` | добавить юнитов / показать типы фракции |
| `build <здание> <уровень>` | установить уровень (кап по замку действует) |
| `build max` | все здания до уровня замка |
| `shield <часы>` / `shield off` | выдать / снять щит |
| `faction highland\|tsars\|sultans\|shogun` | сменить фракцию бесплатно |
| `clearqueue` | очистить все очереди |
| `god` | макс. ресурсы + здания + 500 каждого юнита |
| `reset` | полный сброс прогресса |
| `help` | список команд |

## Боты

Tsarina, Ayato, Lushii, Condorin, Richer — разные фракции и уровни силы; при генерации
двое случайно получают щит. Lushii — лёгкая первая цель.
